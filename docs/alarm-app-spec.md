# ModelY Alarm App — Product Spec v0.1

## Product principle
- 기본 알람 동작이 가장 먼저 신뢰되어야 한다.
- 화면은 홈/설정 2탭을 유지하고 알람 추가·편집은 모달 시트로 처리한다.
- 광고는 알람 발생/종료 핵심 동작을 방해하지 않는다.

## Alarm editor
- 시/분 각각 손가락 위·아래 스와이프 휠
- 위/아래 버튼으로 1단위 증감
- 시/분 직접 숫자 입력
- 알람 개수 제한 없음(10개 이상 가능)
- 반복 요일, 이름, 스누즈, 페이드 인
- 소리 10종
- 진동 패턴 10종
- 무음 화면 플래시

## Settings
- 한국어 / English / 日本語 / 中文 / Français
- 시스템 / 밝은 / 어두운 테마
- 12/24시간 형식
- 기본 스누즈
- 무음 플래시
- 페이드 인

## Ads
- 홈 하단 배너 광고 자리
- 앱 종료 흐름의 전면 광고는 추후 SDK 연결
- 알람이 울리는 중에는 광고 금지

## Privacy
- 스토어 제출용 개인정보처리방침은 공개 GitHub URL 또는 GitHub Pages URL로 제공한다.

## Validation
- Paperthin: 핵심 흐름 단순화와 범위 통제
- Harness Engineering: 정적 분석 → 단위 테스트 → 알람 기능 검증 → 3기기 UI 캡처 → 회귀 검증
