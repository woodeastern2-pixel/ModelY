# VoC Mate 내장 Qwen

Windows용 Qwen 포함 설치본은 Qwen3-1.7B Q8_0 모델과 llama.cpp 실행 엔진을 함께 배포합니다. Ollama 설치, 인증키 입력, 최초 실행 시 모델 다운로드가 필요하지 않습니다. 모델 파일만 약 1.83 GB이며 프로그램 및 실행 시 메모리 공간이 추가로 필요합니다.

- 새 설치의 기본 연결은 내장 Qwen입니다. 기존에 저장한 외부 연결 설정은 자동으로 바꾸지 않습니다. 기존 사용자는 설정 > AI 설정 > 내장 Qwen을 선택하고 저장 및 연결 확인을 실행합니다.
- 모델은 첫 요청에 실행됩니다. 사용하지 않은 상태가 5분간 지속되거나 앱이 종료되면 종료됩니다. 최초 요청에는 파일 검증과 모델 준비 시간이 필요합니다.
- 내장형의 질문과 참고 자료는 해당 PC의 임시 인증된 루프백 연결에서만 처리합니다. 검색도 앱 내부에서 처리합니다. 기존 공유·업무 도구 기능을 사용자가 실행하면 해당 설정에 따라 통신할 수 있습니다.
- 요청은 한 번에 하나씩 처리합니다. 긴 입력이나 불완전한 생성은 오류로 안내합니다. 속도는 사용자 PC 성능과 입력 길이에 따라 달라지며 5초 이내 응답을 보장하지 않습니다.
- 내장 모델도 잘못된 내용을 생성할 수 있습니다. 기존 매뉴얼 근거 확인과 담당자 승인 절차를 유지합니다. Windows 외 플랫폼에는 모델을 포함하지 않습니다.

## 배포 재현

`tool/prepare_bundled_qwen.py`는 빌드 단계에서만 공식 배포 파일을 다운로드합니다. 모델은 Qwen 공식 저장소의 고정 리비전과 SHA-256으로 검증하고, 실행 엔진도 고정 릴리스와 SHA-256으로 검증합니다. 원본 라이선스와 모델 카드를 설치 폴더에 함께 포함합니다. 실행 시 모델 해시를 검증합니다.

`integration_test/bundled_qwen_smoke_test.dart`는 실제 Windows 실행 엔진과 모델을 사용하여 한국어 알림 안내, 근거에 없는 정책에 대한 응답, 네이티브 자식 프로세스 관리 연결을 검증합니다. 이 검사는 전체 업무 질문의 답변 정확도를 보장하는 품질 평가가 아닙니다.
