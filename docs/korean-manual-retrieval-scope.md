# 한국어 원문 우선 검색 개선 — 2026-10-24

## 고정 요구사항

- 이미 등록된 한국어 매뉴얼 원문·표·이미지 인식 자료를 활용한다.
- 영어 매뉴얼과 그 파생 지식을 배포 자산 및 기존 설치의 활성 검색 자료에서 제거한다.
- 문의 초안과 코파일럿의 원문 검색 경로를 통합한다.
- 질문 의도·여러 질문·절차·조건을 함께 검색하고 원문 출처를 보존한다.
- 검색 준비는 등록/갱신 시 수행하며 질문마다 전체 자료를 읽지 않는다.
- 가상 실행에서 실제 한국어 매뉴얼로 검색, 답변, 기존 데이터 보존, 화면을 검증한다.
- Windows 설치 EXE 및 Android APK를 모두 빌드하고 직접 다운로드로 전달한다.

## 보호 대상

승인 화면 구성·색상·아이콘, 기존 문의·답변·설정·공유 기능을 유지한다. 영어 매뉴얼 제거는 사용자의 이번 명시적 변경이다. 문의 기록은 매뉴얼과 구분하여 보존한다. 원본 사용자 파일을 임의 삭제하지 않는다.

## 자료 확인

- 시작 커밋: 3c33a98d0ff23301992094efa1ca0e597353b578.
- 한국어 Word 자료 6종, 한국어 공식 메일 원문이 이미 포함되어 있다.
- 한국어 메신저 v8.5.5 PDF는 NASCA 문서보안 적용 파일로 추출할 수 없다. 이미 등록된 brityworks 한국어 Word의 메신저 원문을 사용한다. 읽지 못한 PDF를 읽었다고 표시하지 않는다.
- 폐기 대상: 2020 영어 messenger-desktop/mobile 원문과 해당 seed/번역 표시 파생물. 재유입 방지도 검증한다.

## 구현

- 영어 원문 2종(69개 구간), 영어 출처 파생 자료 208건을 배포와 활성 검색에서 제거한다. 기존 설치는 검색 자료 버전 2로 전환한다. 새 영어 문서 등록과 영어 자료가 들어 있는 백업 복원을 차단한다.
- 한국어 원문 7종, 5,825개 구간과 한국어 지식 자료 800건을 유지한다. 원문 본문·OCR·이미지 참조가 변경 전과 동일함을 확인했다. 제품 구분은 원문 구간별로 보정했다.
- 역색인, 정규화 문장, 검색용 구간을 자료 변경 시 준비하여 저장한다. 질문당 최대 4회, 회당 최대 128개 후보를 확인한다. 수정·삭제·승인 상태 변경 시 색인을 갱신한다.
- 답변 초안과 코파일럿 모두 같은 색인으로 검색한다. 미답변 VOC는 대화 맥락으로만 사용하고 해결 근거로 사용하지 않는다.
- 질문별 근거를 최대 8개 선택하며 절차·조건을 임의 절단하지 않는다. 내장 모델에는 더 작은 입력 예산을 사용한다. 모델 호출을 늘리는 검색어 재작성은 사용하지 않는다.
- 질문과 제품을 맞추고 기능 소개보다 실제 조작 절차를 우선한다. 한국어 표현 별칭과 복합 질문을 지원한다. 출처·버전 근거가 부족하면 확인 필요를 표시한다.

## 로컬 가상 검증

Flutter 3.47.2 / Dart 3.13.2, Linux Flutter test 환경이다. 실기기 검증은 사용자 요청에 따라 가상 검증으로 대체했다.

- `flutter analyze --no-fatal-infos --no-fatal-warnings`: 오류 0건. 기존 커밋과 동일한 warning/info 98건이며 새 항목은 없다.
- 전체 자동 검사 중 238건 통과. 초기 실행·동기화·비밀번호 보존 검사 1건은 병렬 실행 중 30초 제한을 초과했으며, 단독 실행에서 27초에 통과했다. 배포 워크플로는 검사 동시 실행 수를 1로 제한한다.
- 한국어 원문만 있고 FAQ는 0건인 검색, 색인 재시작, 수정·삭제, 복합 질문, 제한 조건, 영어 자료 제거/재유입 차단을 검증했다.
- 59회 검색·근거 구성 측정: 중앙값 45.26ms, 최대 375.26ms. 모델 추론 시간 및 최초 색인 준비 시간은 포함하지 않는다.
- 가상 문의 1,000건: 모델 호출 없이 721건은 근거가 있는 초안, 279건은 추가 확인 안내를 구성했다. 이는 정확도 점수가 아니다. 병렬 회귀 검사와 함께 수행한 스트레스 실행은 총 645.4초, 가장 느린 요청 19.2초로, 모든 질문에 위 59회 측정값을 보장하지 않는다.
- 반응형 10개 화면/배율 조합, 라이트·다크 화면 및 기준 이미지 7개 비교를 수행했다. 이전 커밋의 실제 화면을 같은 Flutter 버전으로 재생성하고 버전 표시만 정규화하여 비교했다. 이전 승인 화면 구성은 유지했다.
- 단기 수신 서버를 띄우는 녹화용 보조 테스트는 `recording` 태그로 구분한다. 일반 검사 명령은 `flutter test --concurrency=1 --exclude-tags=recording`이다.

## 플랫폼 빌드와 네이티브 가상 실행

로컬 Windows 빌드는 Linux 호스트라 지원되지 않았으며, APK 빌드는 Android SDK 부재를 확인했다. 따라서 `.github/workflows/korean-manual-release.yml`의 품질 게이트 이후 플랫폼 빌드를 사용한다.

- Windows: release 빌드, Windows 가상 머신에서 실제 SQLite/한국어 원문 검색, 실제 내장 Qwen과 한국어 원문 기반 답변 및 근거 없는 수치 거절, Qwen 포함 설치 EXE 패키징.
- Android: API 35 가상 기기에서 실제 SQLite/한국어 원문 검색과 근거 화면, release APK 빌드.
- 실행 결과와 플랫폼별 시간 측정은 워크플로 산출물의 JSON에 기록한다. 성공 여부는 해당 커밋의 Actions 실행 결과로 확인한다.
- 기존 업로드 PDF의 NASCA 보안 잠금은 해제하지 않았다. v8.5.5 문서 내용을 검증한 것으로 간주하지 않는다.

## 네이티브 검증에서 확인한 보완

첫 플랫폼 실행에서 Windows/Android 원문 검색은 통과했고 Android release APK가 생성됐다. Windows 내장 Qwen 검사에서는 일반 초안 프롬프트의 응답이 512토큰 제한에 걸렸다. 내장 모델용 프롬프트를 질문에 필요한 절차·조건에 집중하도록 분리하고, 중복 출처 제목·참고 문구 대신 답변·신뢰도·출처 ID의 세 필드만 생성하도록 줄였다. 출력 중단을 오류로 처리하는 기존 보호는 유지하며, 같은 한국어 원문과 실제 모델로 재검증한다.
